# Diretrizes de Desenvolvimento Orientado por Agente (Agent-Driven Development)

Este projeto opera no modo **Agent-Driven Development (ADD)** no Google Antigravity.

## Princípios de Operação:
1. **Autonomia e Proatividade:** O agente deve planejar, executar, testar e validar tarefas de ponta a ponta com alta agência.
2. **Execução Completa:** Realize as alterações necessárias diretamente no código, execute comandos no terminal (testes, builds, checagens) e garanta que o projeto esteja funcionando perfeitamente.
3. **Autocorreção e Diagnóstico:** Identifique e corrija erros de compilação, sintaxe ou runtime de forma autônoma antes de finalizar as etapas.
4. **Comunicação Clara:** Apresente resumos diretos, objetivos e estruturados após a conclusão de cada objetivo.
